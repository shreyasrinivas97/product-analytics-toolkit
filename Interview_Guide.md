# Interview Guide — Product Feedback & Feature Prioritization
## 60-second explanation
“I created a product-management portfolio case study to demonstrate how I would turn user feedback into a clear backlog. I analyzed 600 synthetic feedback records using Python and SQL, ranked feature ideas with a transparent impact/confidence/effort framework, wrote a lightweight PRD with user stories and acceptance criteria, designed an A/B test measurement plan, and prepared QA/UAT scenarios. I also built an Excel summary dashboard. The data is synthetic, so I treat the results as a demonstration of process rather than real customer evidence.”

## Questions to prepare
**Why this project?** It mirrors product intern responsibilities: user-first thinking, research synthesis, prioritization, specs, metrics, cross-functional execution, and release readiness.

**Why this scoring formula?** It creates a consistent starting point for discussion. Scores are subjective, so I would calibrate them with Product, Design, Engineering, and user evidence. I would also consider dependencies and strategic fit.

**How would you validate the insights?** Review real event funnels, conduct 5–8 exploratory user interviews/usability sessions as a starting point, analyze support tags, and check whether themes differ by segment. The sample size and research design should be appropriate to the decision.

**What if the A/B test is inconclusive?** Check instrumentation, assignment balance, sample size, confidence intervals, and guardrails. Avoid repeatedly checking results or changing metrics after launch. Consider a follow-up test or qualitative research.

**What did you learn?** Product management is not just choosing features: it is framing the problem, clarifying trade-offs, defining measurable outcomes, and making execution unambiguous.
